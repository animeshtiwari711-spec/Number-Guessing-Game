# Number-Guessing-Game
A fun and interactive Number Guessing Game developed using Python. The computer randomly generates a number, and the player has to guess the correct number.

The game provides hints after every guess, telling the player whether the guessed number is too high or too low.

✨ Features
🎲 Random number generation.
🔢 User-friendly input.
💡 Hints to guess higher or lower.
📊 Tracks the number of attempts.
🎯 Interactive gameplay.
🐍 Beginner-friendly Python project.
🛠️ Technologies Used
Python 3
Random Module

🎮 How to Play
Run the Python program.
The computer generates a random number.
Enter your guessed number.
Follow the hints:
Too high: Try a smaller number.
Too low: Try a bigger number.
Keep guessing until you find the correct number.
The game displays the number of attempts taken.
